## 朵菈 · 矿灯修理工

烟灰围裙，额灯罩有一道斜裂；短辫末端缠着旧布。

声线：先问东西哪里坏了，再说别的；温和但不许逞强。

边界：认识来往矿工；布洛克可得到熟人式称呼，但她不是炸矿主线证人，也不知道私卖遗物。

### 看得清的标记 `local.dwarf.lamp_labels`

同色灯牌让交班矿工拿错待修灯。把可用、待修两组重新标清。

> 灯不认谁嗓门大。坏罩和好罩得分开。
> 这边是裂罩，那边缺扣。你看怎样最不易拿错？

- 按形状分牌 → 你刻缺口，我画横线。手脏也摸得出来。 → 灯架改用缺口／横线双标记；后续问候承认玩家选择。
- 按存放位置分架 → 行。好灯靠出口，待修灯往里放。 → 改为内外两架并加提示。

### 别把灯绑在腕上 `local.dwarf.strap_repair`

用一份普通铁屑修好灯架松脱的扣环；选择优先补公用架还是交班架。

> 我修的是灯架，不是给你打造新盔甲。
> 普通铁屑就够，亮得扎眼的好料留着。

- 先补公用架 → 那就先让赶着出门的人有灯拿。 → 公用灯架扣环修好，任务记一次完成。
- 先补交班架 → 好，先让交班的人别把灯摔在地上。 → 交班架固定完成，后续对白不同。

## 赫珀 · 冷泉配料员

宽布帽裹着耳朵，手套有浅蓝苔痕；腰间挂空量杯。

声线：报品名很准，遇到争执就把东西摊开给人看。

边界：供应矿工日常配料，不会凭材料认出遗物核心；可复用为归途事件在本区的 NPC。

### 这批别混 `local.dwarf.moss_batch`

本批石胆菌分装缺料；赫珀用库存灰根草交换，补充玩家的基础配料。两份普通石胆菌换一份普通灰根草，不自动投入高品质。

> 石胆菌和寒泉苔别混。我这批还缺石胆菌。
> 交两份普通石胆菌，领一份普通灰根草。

- 标成当批补入 → 这一格写你补入的，不改旧账。 → 两份普通石胆菌被消耗；当前批登记完成；领取一份普通灰根草。
- 单独装袋 → 单袋也好，谁领走都知道装的是什么。 → 同样扣两份普通石胆菌；本批改为独立袋签；领取一份普通灰根草。

### 两个筐的争执 `local.dwarf.two_baskets`

一筐干料、一筐湿料被贴错标签。听完两位工人的要求后由赫珀重新分装。

> 他们都说我少给了。其实谁都拿错了筐。
> 要先逐人换回，还是摊开重新认领？

- 逐人对签换回 → 慢一点，但每个人都能看见自己的那份。 → 赫珀逐袋对签；争执结束，不改玩家物资。
- 摊开重新认领 → 都退一步，我把签放在筐前。 → 公开核对筐签。

> 你要我写“能通”，得拿出亲眼所见。

- 标作未经核验 → 问号留着。它比一句瞎保证有用。 → 任务日志新增“未核验支路”的地方记录。
- 暂时遮去支路线 → 遮，不是擦。等有人核实再翻出来。 → 纸图覆盖该线但保留原稿。

### 回来再画线 `local.dwarf.survey_after_clear`

> 在银纹矿廊走一趟，回来只说你见到的。
> 我不收“听说已经安全”，也不保证下一次没人拦路。
> 本轮回报后领一份普通灰根草，不另发金币。

- 记下遇敌位置 → 把位置圈上。下个人至少知道在哪里放慢脚。 → 本轮巡查记录标成“有活动敌情”；领取一份普通灰根草。
- 记下撤回路径 → 这条线写“可撤回”，不写“永远安全”。 → 本轮记录撤回路径；领取一份普通灰根草。

- 先腾出干净位置 → 把地腾出来，错袋就不会又混回去。 → 整理仓内分区再核对。

### 一小份留种 `local.human.one_seed_measure`

> 只收普通白穗籽，一份也记清楚。

- 补入公用袋 → 眼前的缺先补上。明天的账还得继续算。 → 消耗同一份材料，日志记为公用补给。
