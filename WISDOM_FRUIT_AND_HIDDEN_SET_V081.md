# v0.81 fruit and ordinary-dungeon reward correction

Supersedes the fruit/pity rules in RARE_IDLE_REWARDS_V079.md and v0.79 release notes.

- 灵慧之果 retains `consumables.memoryFruit` inventory key, preserving all owned units (including stacks of 5000) and queued fruit. Explicit use consumes exactly one and adds three permanent unallocated talent points. `earnedFruitTalentPoints` is optional, integer, nonnegative, divisible by three, <=3,000,000,000. Budget = level − 1 + earned points. Retired `bonusTalentPoints` remains rejected. Existing allocations/caps remain unchanged.
- Use requires stopped expedition and no active battle; expected inventory quantity rejects stale actions. App uses clone-save-adopt persistence; quota failures cannot consume fruit or award points. A short UI lock blocks duplicate rapid clicks.
- Fruit no longer pays for refunds. Historical refund credits remain usable; otherwise existing 20 gold/point policy and early/free correction policies apply.
- No historical elf specialty drop rate existed in production/docs. Approved rates: one roll per real won encounter in an elf **region**, independent of hero race: field 0.5%, each ordinary-dungeon stage 1%, boss 2%. Existing luck occurrence adjustment applies once. No return-ring material bonus. Tower, story, failures, duplicate settlements, other regions: no fruit.
- No new merchant fruit offers. Historical unpurchased offers remain valid save data but are visibly retired and cannot be bought or charge money. Already owned/pending fruit is untouched.
- v2 hidden rare state retires v1 clear-based drought and unfinished fruit progress without conversion. Earned pending quantities and exact equipment identities survive. Migration occurs before the first new ordinary reward event; v1 read/claim remains accepted for old saves.
- Ordinary dungeon gear events in set-eligible regions (A03–A10) increment the counter **before** filter/capacity checks. On the twentieth generated gear event, replace that item with a protected set, reset count. Empty gear rolls do not count. All dungeon stages qualify. Field/boss/tower don't increment.
- Natural set chance remains independent: 8% complete ordinary-dungeon clear, 12% boss, with existing luck formula. Natural dungeon set resets dungeon counter; boss set does not alter it. Replacement and natural set may coexist on the same final stage. Reserve two pending slots before entering a normal encounter; max queue remains 1000. Sets bypass quality discard and retain identity when full.
- No counters, thresholds or fruit-progress explanations appear in UI/reward notes. Pending claims and actual natural drop probability help remain available.

Verification: wisdom-fruit-v081-tests.mjs, wisdom-fruit-ui-tests.cjs, updated talent-tests.mjs and talent-balance-v071-tests.mjs. Otherworld core/loot-offline regressions passed after change. Rewritten rare-idle-rewards-tests.mjs covers actual all-stage events, natural independence, filtering/overflow, old-save migration, regional specialty all sources and cross-race visitors, two-set pending998→1000 boundary and offline parity. rare-loot-ui-tests.cjs verifies five old/full/failure/running/normal modes with no visible hidden counters.
