# Unified equipment set names

All 15 sets / 60 pieces use `套装名·装备名` on player-facing screens. The 12 human pieces gain their canonical set name, and the 24 elf/goblin pieces gain the missing separator. Dwarf and Ashen pieces already match and remain unchanged. Examples: 赤痕誓约·赤痕盔, 逐叶弦歌·额冠, 苦菌行者·兜帽.

The helper resolves real set/template IDs, not guessed item categories. Existing serialized names, IDs, costs, stats, affixes, growth, reward reservations and transaction fingerprints are untouched. This keeps historical saves and committed pending rewards valid. Pre-template set items retain their original piece name under the known set prefix. Non-set and legendary names remain unchanged. There is no equipment rename feature to overwrite.

Consumers: current and legacy inventory layouts, equipped slots/tooltips, equipment icons and accessible labels, loadout wardrobe, enhancement, all reforge previews and donor labels, fusion inputs/results, merchant equipment cards, casino selection/search/receipts/toasts, loot history and new battle reward notes. Old structured receipts resolve exact known item-name aliases for display only; arbitrary prose is not substring-rewritten.

Validation: `node set-name-unification-v087-tests.mjs` exhaustively covers all 60 pieces and legacy identity preservation. `node set-name-unification-app-ui-v087-tests.cjs` runs the actual app with a legacy human set through inventory, paid reforge both sides and reload. Existing equipment-template, pure pixel-inventory, inventory-bags UI, loadout UI, reforge UI, inheritance UI, forge-workflow UI, equipment-raster, integrated-monster-codex UI and v086 special-preservation tests pass.

Independent review caught and fixed an accidental monster-name substring replacement and a missing reforge comparison label before handoff. Added regression coverage. `pixel-inventory-app-ui-tests.cjs` fails the existing 回忆之果 assertion identically on untouched v086 baseline; it was not weakened or counted as passing.

Browser fixture: `qa/v087-set-names/legacy-human-set-save.json` (generated by the focused test). Final browser and release resource graph verification belong to v087 integration. No independent publication.
